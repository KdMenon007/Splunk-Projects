
---
## 1. Find All SharePoint Activity

```spl
index=m365 Workload=SharePoint
```

**Use:** Starting point for any SharePoint investigation.

**Meaning:**

```text
index=m365       → Search Microsoft 365 logs
Workload=SharePoint → Only SharePoint events
```

---

## 2. Make SharePoint Events Readable

```spl
index=m365 Workload=SharePoint
| table _time UserId Operation SourceFileName ObjectId SiteUrl
| sort _time
```

**Use:** Quickly build a chronological timeline.

**Focus on:**

- `UserId` → Who
    
- `Operation` → What
    
- `SourceFileName` → Which file
    
- `ObjectId` → Which object
    
- `SiteUrl` → Which SharePoint site
    

---

# 🔐 Authentication / User Investigation

## 3. Investigate One User

```spl
index=m365 Workload=SharePoint UserId="emily.turner@tryhackme.thm"
| table _time Operation SourceFileName ObjectId SiteUrl ApplicationDisplayName UserAgent
| sort _time
```

**Use:** Investigate everything a particular user did in SharePoint.

**Think:**

```text
WHO → WHAT → WHEN → WHICH FILE → WHICH APPLICATION
```

---

## 4. Count SharePoint Activity by User

```spl
index=m365 Workload=SharePoint
| stats count by UserId
| sort - count
```

**Use:** Find users generating unusually high volumes of SharePoint activity.

⚠️ High activity ≠ malicious. Compare against the user's normal role.

---

# 📂 File Access

## 5. Find File Access

```spl
index=m365 Workload=SharePoint Operation=FileAccessed
| table _time UserId SourceFileName ObjectId SiteUrl
| sort _time
```

**Use:** See which users are opening/accessing SharePoint files.

Useful for detecting:

- Reconnaissance
    
- Sensitive-file discovery
    
- Account compromise
    

---

## 6. Find Sensitive-Looking Files

```spl
index=m365 Workload=SharePoint Operation=FileAccessed
| search SourceFileName="*password*"
    OR SourceFileName="*credential*"
    OR SourceFileName="*secret*"
    OR SourceFileName="*contract*"
    OR SourceFileName="*finance*"
| table _time UserId SourceFileName ObjectId SiteUrl
```

**Use:** Hunt for access to potentially sensitive documents.

⚠️ Filename alone does **not** prove malicious activity.

---

# ⬇️ File Download / Exfiltration

## 7. Find Downloads

```spl
index=m365 Workload=SharePoint Operation=FileDownloaded
| table _time UserId SourceFileName ObjectId SiteUrl
| sort _time
```

**Use:** Investigate files downloaded from SharePoint.

This is one of the most important queries for **data-exfiltration investigations**.

---

## 8. Count Downloads by User

```spl
index=m365 Workload=SharePoint Operation=FileDownloaded
| stats count as download_count by UserId
| sort - download_count
```

**Use:** Identify users downloading unusually large numbers of files.

Example:

```text
Normal user → 10 downloads
Suspicious user → 1,500 downloads
```

---

## 9. Detect Download Spikes

```spl
index=m365 Workload=SharePoint Operation=FileDownloaded
| bin _time span=1h
| stats count as downloads by _time UserId
| sort - downloads
```

**Use:** Detect sudden bursts of downloading.

Example:

```text
10:00 → 5
11:00 → 8
12:00 → 7
13:00 → 900 🚨
```

---

## 10. Find Downloaded Files by Folder

```spl
index=m365 Workload=SharePoint Operation=FileDownloaded
| stats count values(SourceFileName) as files by UserId SourceRelativeUrl
| sort - count
```

**Use:** Identify users/folders involved in bulk downloads.

Important because downloading a folder can generate **one event per file**.

# 🕵️ External Application / Rclone

## 22. See Applications Used

```spl
index=m365 Workload=SharePoint
| stats count by UserId ApplicationDisplayName
| sort - count
```

**Use:** Discover which applications users are using to interact with SharePoint.

---

## 23. See User Agents

```spl
index=m365 Workload=SharePoint
| stats count by UserId UserAgent
| sort - count
```

**Use:** Identify unusual clients/tools.

⚠️ Don't automatically treat strange SharePoint user agents as malicious.

---

## 24. Hunt for Rclone

```spl
index=m365 Workload=SharePoint
| search ApplicationDisplayName="*rclone*"
    OR UserAgent="*rclone*"
| table _time UserId Operation ApplicationDisplayName UserAgent ObjectId
| sort _time
```

**Use:** Hunt for Rclone-based SharePoint synchronization.

🚨 Especially interesting when Rclone is unusual for the user.

---

## 25. Find Users with Many Applications

```spl
index=m365 Workload=SharePoint
| stats dc(ApplicationDisplayName) as app_count
    values(ApplicationDisplayName) as applications
    by UserId
| sort - app_count
```

**Use:** Identify users with unusual application diversity.

# 🦠 Malicious SharePoint File Investigation

Assume the malicious file is:

```text
BADFILE
```

## 26. Find Who Uploaded It

```spl
index=m365 Operation IN(FileUploaded, FileCreated)
ObjectId="*BADFILE*"
| table _time UserId Operation ObjectId
| sort _time
```

**Question answered:**

> Who introduced the suspicious file into SharePoint?

---

## 27. Find Who It Was Shared With

```spl
index=m365 Operation IN(AddedToSecureLink, SharingSet)
ObjectId="*BADFILE*"
| table _time UserId TargetUserOrGroupName ObjectId
| sort _time
```

**Question answered:**

> Who received the malicious/suspicious file?

---

## 28. Find Who Opened It

```spl
index=m365 Operation IN(SecureLinkUsed, AnonymousLinkUsed, FileAccessed)
ObjectId="*BADFILE*"
| table _time UserId Operation ObjectId
| sort _time
```

**Question answered:**

> Who actually interacted with the file?

---

# 🧩 Full Timeline Investigation

## 29. Build Timeline for a File

```spl
index=m365 ObjectId="*BADFILE*"
| table _time UserId Operation SourceFileName TargetUserOrGroupName ObjectId SiteUrl
| sort _time
```

**Use:** One of the most valuable investigation queries.

You may see:

```text
FileUploaded
      ↓
AddedToSecureLink
      ↓
SecureLinkUsed
      ↓
FileAccessed
      ↓
FileDownloaded
```

That's your attack story.

## 🔥 Mental Model

Don't memorize the queries as random Splunk syntax. Map each one to the investigation question:

```text
WHO?
 ↓
UserId
 ↓
WHAT DID THEY DO?
 ↓
Operation
 ↓
WHICH FILE?
 ↓
ObjectId / SourceFileName
 ↓
DID THEY DOWNLOAD?
 ↓
FileDownloaded
 ↓
DID THEY SHARE?
 ↓
SharingSet / AddedToSecureLink / AnonymousLinkCreated
 ↓
DID SOMEONE USE IT?
 ↓
SecureLinkUsed / AnonymousLinkUsed
 ↓
DID THEY USE AN UNUSUAL TOOL?
 ↓
ApplicationDisplayName / UserAgent
 ↓
WHAT IS THE STORY?
 ↓
Timeline
```

**That's the SharePoint SOC workflow:**  
**Authenticate → Access → Collect → Share → External Access → Exfiltrate → Build Timeline.**
