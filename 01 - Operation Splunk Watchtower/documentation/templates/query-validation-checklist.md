# Query Validation Checklist

-   [ ] Confirm the intended index exists.
-   [ ] Confirm sourcetype and data source.
-   [ ] Select and document a time range.
-   [ ] Verify fields in raw events and the field sidebar.
-   [ ] Run the base search before adding commands.
-   [ ] Record result count and representative events.
-   [ ] Validate aggregation and ordering semantics.
-   [ ] Confirm the query is suitable for the intended data volume.
-   [ ] Screenshot the query and result state.
-   [ ] Separate observation, inference, and conclusion.
-   [ ] Sanitize sensitive values before sharing publicly.
